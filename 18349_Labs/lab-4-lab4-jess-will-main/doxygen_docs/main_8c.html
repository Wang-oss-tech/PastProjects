Detailed Description

creates a system where tasks are managed concurrently using FreeRTOS, and it interacts with various peripherals like LEDs, UART, LCD, keypad, and servo motors. The primary functionality involves handling commands through UART and controlling the servo motor based on user input passcodes. The program also includes a simple LED toggle task and UART input/output tasks.
