void disable_exti ( uint32_t  channel)

Disable External Interrupt (EXTI) for a specific channel.

This function disables the EXTI for the specified channel, preventing the corresponding external interrupt from triggering further interrupts. It clears the EXTI Interrupt Mask Register (EXTI_IMR) for the specified channel.

Parameters
channelThe EXTI channel to be disabled.
