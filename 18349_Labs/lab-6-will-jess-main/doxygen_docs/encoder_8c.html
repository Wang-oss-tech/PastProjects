Detailed Description

This file contains the implementation of an encoder interface for FreeRTOS. The encoder is connected to two GPIO pins, and changes in its rotational state are captured using interrupts. The current position of the encoder is tracked and can be read using the encoder_read() function.

void encoder_irq_handler ( )

Interrupt service routine (ISR) for handling encoder events.

This ISR is triggered by changes in the state of the encoder. It updates the current position of the encoder based on the transition between its two signals (ENC A and ENC B). The function also takes care of handling overflow by resetting the position to zero when it reaches a predefined maximum value.
